# ControlBoxForCustom(WPF)

**コントロールボックスを一括で置けます！**

- 追加されてる便利な機能
  - ネイティブヒットテスト（ **HTMAXBUTTON** , **HTMINBUTTON** , **HTCLOSE** )
    - HTMAXBUTTONがあるため、 **Windows 11** 以降で追加された **SnapLayouts** 対応。 
  - WPF XAML標準属性の **Background** / **Foreground** にも対応。

# このプロジェクトのソースコードをビルドする場合

- 必要なアプリまたはSDK
  - .NET 11 SDK
